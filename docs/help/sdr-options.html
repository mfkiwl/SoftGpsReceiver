SDR options

The program streams directly only from radios supported by the Ettus UHD driver. Other radios can be used by recording to a file with their own tools and processing it afterwards; live streaming from them would need a new input added to the program.

Live streaming (UHD)

RadioLinkNotes
USRP N200 / N210Gigabit EthernetNeeds a daughterboard covering 1575.42 MHz: DBSRX2, WBX, SBX or UBX. The rate is 100 MHz divided by an integer. This is the radio the live mode was written for.
USRP B200 / B210 / B205miniUSB 3Should work through UHD; set the device address (for example type=b200). Use a bias tee unless you have confirmed antenna power.
USRP X300 / X310EthernetShould work through UHD with a suitable daughterboard. More capable than this job needs.

The code has been checked against the real UHD 4.11 driver, but has not yet been run with any real radio.

Record, then process

Capture with the radio's own software at L1 (1575.42 MHz), then use File > Open. The file name gives the rate, IF and format, for example capture-fs4-if0-int8iq.bin for 4 MS/s centred on L1.

RadioTypical sample formatNotes
HackRF Oneint8 I/QCan power an antenna. 8 bits, so set gain with care.
bladeRFint16 I/QUse a name containing int16iq.
LimeSDR, ADALM-Plutoint16 I/QDepends on the capture tool. Check the clock stability of your model.
RTL-SDRunsigned 8-bit I/QCheap, about 2 to 2.4 MS/s, so GPS only. This format is not read directly: convert to int8 I/Q by subtracting 128 from each byte. Some models can power an antenna.

Check each radio's current specification before buying; capture formats depend on the tool used.

Sample rate

GPS works from 2 MS/s. Galileo needs at least 4 MS/s. The default of 5 MS/s suits both.
