Connecting a USRP N200

  1. Install UHD from https://files.ettus.com/binaries/uhd/. The program looks in UHD_PKG_PATH, C:\Program Files\UHD\bin and PATH.
  2. Connect the network. Use a wired gigabit port; Wi-Fi cannot carry the stream. Give that port the static address 192.168.10.1, mask 255.255.255.0. The N200 ships as 192.168.10.2.
  3. Check the radio. The firmware and FPGA image must match UHD, and the probe reports it if they do not. 
    uhd_find_devices
uhd_usrp_probe --args addr=192.168.10.2
  4. Connect the RF chain with the DC supply off: antenna to the bias tee RF+DC port, bias tee RF port to the N200 RX2 port.
  5. Power the antenna. Set the supply to the antenna's voltage, connect it to the bias tee DC port and switch on. A current near the antenna's rating shows that its amplifier is running.
  6. Configure the program: see Settings for live mode.
  7. Press F10. Satellites should appear within seconds. The first position takes about 30 to 60 s, because each satellite's orbit has to be read from its signal.
